# NS-PARAM-NAMING namespace-call addendum — capture instructions v1

This addendum selects all 24 exact ADMISSION-DELTA-v1 IDs (one source per namespace/version) and six exact TA-PROGRAMS-v1 ta-parameter sources: w0Value, sma and ema in v5/v6. All 30 are native questions. No producer expected value or local admission/refusal is a TradingView prediction.

The namespace-call names are array, box, color, label, line, linefill, map, math, matrix, polyline, str and table. Each source declares a Holder-typed parameter with that name, executes a builtin namespace operation in the body, then calls its custom w0Value method. The ta sources separately exercise the custom w0Value/sma/ema methods. No builtin TA output or broad TA claim is requested.

This group supplements the staged field-only and non-UDT explicit-namespace probes; it does not replace or alter them.
